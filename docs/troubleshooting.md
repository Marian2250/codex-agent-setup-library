# Troubleshooting

## The skill or roles do not appear

Confirm the actual working folder and that copying kept hidden .agents and .codex directories. Check your installed version's documented discovery behavior. You can still ask the main session to read the source-brief SKILL.md explicitly. Custom-role availability is optional for this exercise.

## The report was not saved

Check whether the session has access to this working folder and permission to write reports/. If it only returned text in chat, review that text and save it yourself. A chat response is not proof that a local file exists.

## The report sounds current

The provided source notes are dated. Ask the agent to restore the snapshot date, remove unsupported current-capability claims and identify what needs a live check before use.

## The library does not remember saved entries

Some browsers restrict local storage for file URLs. Export your shortlist before closing the page. The library has no server-side account sync.

## A source link changed

Open the publisher's current documentation and find the matching topic. Report the library entry and replacement link in a GitHub issue. A broken reference does not authorize changing your machine settings.

## You want a real business task

Use a fresh task copy. Define its permitted source data, output, finishing checks and allowed actions. Keep information within your approved tools. Add external actions only when they are part of the task you actually authorized.
