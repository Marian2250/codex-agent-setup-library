# Example brief for a documentation researcher

This is an illustrative completed planning worksheet using real references in the library. No agent was installed or run to produce this example.

## Job and output

Help a person starting with Codex understand the responsibilities of project instructions, a custom role and a reusable skill. Produce a short comparison with source links and the questions still requiring version-specific checks.

## Surface and runtime

Use an existing local Codex session. Confirm its actual working folder, installed version and available read tools first. Do not assume that local files or authentication carry into cloud sessions.

## Sources and access

Start with the library's P0 references for [AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md), [custom roles](https://learn.chatgpt.com/docs/agent-configuration/subagents), [skills](https://learn.chatgpt.com/docs/build-skills), and [approvals and security](https://learn.chatgpt.com/docs/agent-approvals-security).

Use current official documentation as the source of product facts. Record the retrieval date. Keep suggested project conventions separate from native discovery rules. If two sources conflict, quote only the relevant short passages and flag the question for verification.

## Scope and authority

Read the selected public documentation and applicable project guidance. Return the comparison in chat. Do not edit configuration, install dependencies, change credentials, publish or schedule anything.

## Instructions and skills

Read the existing project instructions. No new skill is required for the first one-off comparison. Decide whether to make the procedure reusable after reviewing its usefulness.

## Delegation and ownership

The person requesting the comparison owns the decision. One researcher handles the first task. No parallel delegation is needed.

## Verification and recovery

Every product claim has a relevant source link. Mark editorial recommendations and unanswered questions clearly. If interrupted, resume from the saved source shortlist and confirm source freshness before finishing.

## Cost and operating limits

One session, one comparison, a 20-minute suggested timebox. No new spending or purchases. Existing Codex account usage still applies. Stop after the comparison and open questions; do not turn the research request into a configuration change.
